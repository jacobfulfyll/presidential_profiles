Rhetorical fingerprint

Eight deterministic lexical and readability measures, pairing each absolute value with its percentile among presidents represented by at least five corpus speeches. Highest relative position: Certainty, 81st percentile. Lowest: Vocabulary, 14th percentile.

Explain this measure

President percentile — The percentage of eligible presidents whose measured value is at or below this one.

The 80th percentile means the value is at least as high as about 80% of eligible presidents.

  1. Calculate the same measure for every eligible president
  2. Exclude records below the five-speech precision floor
  3. Order the values
  4. Report the president's relative position
Formula and limitations

rank among eligible presidents / number eligible · percentile from 0 to 100

A percentile is a relative position, not an absolute amount or a quality ranking.
